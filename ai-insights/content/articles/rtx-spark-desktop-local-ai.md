## NVIDIA RTX Spark 紧凑型台式机现已发售

华硕、戴尔和微星（MSI）的系统现已上市——宏碁、技嘉、惠普和微软的产品也在路上——为本地 AI、开发和创意工作流程带来 RTX 加速和高达 128GB 的统一内存。

2026 年 11 月 18 日 由 [Justin Walker](https://blogs.nvidia.com/blog/author/justin-walker.md) 撰写

![](https://blogs.nvidia.com/wp-content/uploads/2026/11/nv-blog-1280x680-2-1.jpg)

华硕、戴尔和微星推出的全新 [NVIDIA RTX Spark 紧凑型台式机](https://www.nvidia.com/en-us/products/rtx-spark.md) 今日上市，将本地 AI 智能体、图像和视频生成以及模型微调功能带入专用 Windows PC。

凭借高达 128GB 的统一内存和 NVIDIA 的 AI 软件栈，这些系统为更大的本地模型以及经 RTX 加速的创意和开发工具提供了空间。专用台式机可以在笔记本电脑外出或处理其他工作时，保持智能体和计划任务的持续运行。

随着新台式机的推出，不断扩展的软件生态系统将更多的创意和开发工作流程带入 RTX Spark 笔记本电脑和紧凑型台式机。

来自 Adobe 的原生 Windows on Arm 应用程序、Blender 中的 NVIDIA DLSS 光线重建功能以及 ComfyUI 中的本地生成工作流程，扩展了创作者和开发者在 RTX Spark 上的能力——所有操作均在同一台 Windows PC 上完成。

### **专为本地 AI 打造的 Windows PC**

随着工作流程扩展到包括本地 AI 模型和智能体，更多工作可以在活跃编辑会话之外继续进行——从生成资产到处理长渲染或计划任务。

RTX Spark 紧凑型台式机为开发者、创作者和 AI 爱好者提供了一台用于本地模型和全天候运行智能体的专用 Windows PC。它将图像和视频生成、模型微调、创意应用和开发工具整合在一个紧凑的系统中。

在本地运行支持的模型可将本地处理的代码和文件保留在 PC 上，并避免针对这些任务产生按 token 计费的云应用程序编程接口（API）费用。

[![](https://blogs.nvidia.com/wp-content/uploads/2026/11/11-18-Local-AI-Blog-copy-1.jpg)](https://blogs.nvidia.com/wp-content/uploads/2026/11/11-18-Local-AI-Blog-copy-1.jpg)RTX Spark 紧凑型台式机（如华硕 ProArt GR1X 迷你 PC）专为 24/7 运行个人 AI 智能体而设计。

RTX Spark 台式机配备了 20 核 NVIDIA Grace CPU、拥有 6,144 个 CUDA 核心的 NVIDIA Blackwell RTX GPU 以及高达 128GB 的统一内存，可提供高达 1 petaflop 的 AI 性能。10GbE 以太网连接支持在 RTX Spark 紧凑型台式机和网络存储之间快速传输大型数据集、模型文件和创意资产。

这些先进的硬件为创作者、开发者和 AI 爱好者解锁了令人惊叹的能力，包括：

*   在本地运行庞大的 1200 亿参数大语言模型
*   实时渲染 90GB+ 的 3D 场景
*   流畅地实时编辑 4:2:2 视频

[![](https://blogs.nvidia.com/wp-content/uploads/2026/11/MSI-EdgeMesa-N-AI-Series.png)](https://blogs.nvidia.com/wp-content/uploads/2026/11/MSI-EdgeMesa-N-AI-Series.png)微星 EdgeMesa N AI+ 系列 RTX Spark 紧凑型台式机。

华硕、戴尔和微星的新款紧凑型台式机现已可购买，加入了今天发布的 RTX Spark 笔记本电脑系列。宏碁、技嘉和惠普的迷你 PC 即将推出，此外还有 [微软 Surface RTX Spark Dev Box](https://www.microsoft.com/en-us/surface/devices/surface-rtx-spark-dev-box)。

### **从本地智能体到 AI 创作**

原生 CUDA 支持和通过 Windows Subsystem for Linux (WSL) 提供的 Linux 开发工具为开发者构建和运行本地 AI 工作流程奠定了基础。开发者可以使用 Hermes Agent 或 NVIDIA NemoClaw 蓝图设置智能体，并使用 Unsloth 微调支持的模型。

RTX Spark 可以运行连接熟悉的应用程序和本地 AI 工具的创意智能体，帮助创作者通过自然语言指令从想法过渡到完成作品。

NVIDIA Switchyard 现已在 Hermes 中可用，可自动在本地和云模型之间路由智能体任务。日常任务可在设备上运行，而高级推理则利用云模型，从而帮助管理创意工作流程中的云成本。

这些功能通过 Hermes Agent 将 Photoshop 和 ComfyUI 连接起来，形成创意工作流。创作者可以使用自然语言指令，将草图转化为渲染图像和动画，或在设备端完全对图像进行动画处理——从隔离主体并定义其运动到生成最终视频。

[![Adobe MAX 2026 NVIDIA RTX Spark Booth Activation](https://img.youtube.com/vi/nypDHkAyJ5E/hqdefault.jpg)](https://www.youtube.com/watch?v=nypDHkAyJ5E)

_NVIDIA 在 Adobe MAX 上展示了这些工作流，与会者使用自然语言指令，将草图转化为共享的数字迈阿密景观中的渲染图像和动画。_

RTX Video Frame Generation（RTX 视频帧生成）和 RTX Video HDR（RTX 视频高动态范围）功能已在 ComfyUI 中提供，进一步扩展了工作流：生成的片段可以扩展至每秒 60 帧，并转换为高动态范围以进行调色，所有操作均在 RTX Spark 上的单个 ComfyUI 工作流中完成。

### **Adobe 为 RTX Spark 加速整个创意栈**

NVIDIA 和 Adobe 正在扩展 Adobe 创意应用程序中的原生 Windows on Arm 支持和 RTX 加速，帮助视频编辑、摄影师、设计师和 3D 艺术家在 RTX Spark 上更高效地工作。

**Adobe Premiere** 通过 [NVIDIA TensorRT-RTX](https://developer.nvidia.com/tensorrt-rtx) 加速了一系列 AI 驱动编辑功能，包括 Enhance Speech（增强语音）、Object Mask（对象蒙版）、Scene Edit Detection（场景编辑检测）和 Auto Reframe（自动重新构图）——让编辑人员减少等待时间，将更多时间用于剪辑。

GPU 加速还扩展到了 Film Impact 过渡和效果插件。此次更新改进了对专业视频格式的支持，包括 Canon RAW、Red RAW、ARRI RAW、ARRICORE、ARRI HDE、MXF 中的 H.264 和 HEVC、ProRes RAW 以及长 GOP 视频。这使得编辑人员处理日常 H.264 视频交付物的速度提高了 50% 以上。

**Adobe Photoshop** 为 Remove Tool（移除工具）添加了 TensorRT-RTX 加速，并为 ArmRTX Spark 原生提供 Camera Raw 支持，帮助摄影师更快地移除不需要的对象，并在不依赖模拟的情况下处理 RAW 图像。在 Adobe MAX 上，Adobe 预览了一款下一代图像处理引擎，具有广泛的 GPU 加速功能，包括交互式高斯模糊和 Light Leaks（漏光）滤镜。

**Adobe Substance 3D Painter 12.2** 现已针对 RTX Spark 进行优化，并在公共测试版中首次提供 Arm 原生支持。游戏、视觉特效和可视化领域的艺术家可以在 RTX Spark 笔记本电脑和紧凑型台式机上原生运行 Substance Painter，无需任何兼容性层。

**Adobe Illustrator** 和 **InDesign** 现在提供针对 RTX Spark 优化的原生 Windows on Arm 版本。Adobe Illustrator 的性能比其模拟版本高出多达 30%，有助于加速 RTX Spark 上的插图、平面设计和页面布局工作流。

### **Blender 5.3 将 DLSS 光线重建引入视口**

Blender 5.3 将 DLSS 4.5 Ray Reconstruction（光线重建）集成到 Cycles 视口中，帮助艺术家在创作过程中评估光照和材质，获得接近最终质量的实时光线追踪预览。

实际效果立竿见影：光线重建在交互式视口中实时提供接近最终质量的光照、反射和材质，而不是让用户在嘈杂、正在解析的预览中进行导航。

DLSS 4.5 Ray Reconstruction 支持需要 Blender 5.3 以及最新的 NVIDIA Game Ready 驱动程序或 NVIDIA Studio 驱动程序。下载 [NVIDIA App](https://www.nvidia.com/en-us/software/nvidia-app.md) 以在最新驱动程序可用时获得自动通知，从统一的 GPU 控制中心优化游戏和应用程序，并发现最新的 NVIDIA 工具和软件。

### **Windows Server 2028 即将登陆 DGX Station for Windows**

在 Microsoft Ignite 上宣布，Windows Server 正在演进，以满足那些需要将 AI 部署得更靠近企业应用程序和数据的需求。

Microsoft 正在通过支持最新 AI 硅片来扩展硬件选择，帮助客户在自己的环境中利用加速推理和日益强大的模型。由 GB300 Grace Blackwell Ultra Desktop Superchip 驱动的 NVIDIA DGX Station for Windows 平台正在扩展，以支持 Windows Server 2028。

新的加速器平台以及广泛的 Windows 硅生态系统为客户提供了一系列选项，涵盖不同能力层级和价格点，以支持高级 AI 开发、本地推理以及大规模 Agent 工作负载。

### **Windows ML 更新为开发者提供更多选择**

在 Microsoft Ignite 上宣布，开发者现在可以将 Hugging Face 上的任何 GGUF 模型引入 Windows ML，并使用 llama.cpp 后端运行它。

DxCGC 后端目前作为实验性版本提供，这是为游戏开发者提供的集成方案，通过 DirectX 12 编译和运行机器学习模型，使开发者能够在执行图形任务的同时运行 AI 工作负载。

Windows API 允许应用程序集成平台提供的 AI 能力，并为 AION Instruct 和 VSR 添加 GPU 支持。

开发者还可以使用命令行界面为 Windows ML 构建高性能 AI 模型。

🤖 **Runway 的 Praxis-1** 是一个新发布的拥有 270 亿参数的世界动作模型，能够同时预测视频和动作。开发者可以在 NVIDIA GeForce RTX 5090、NVIDIA RTX PRO 6000 Blackwell、DGX Spark 和 DGX Station 上本地运行它，并通过 LoRA 微调将其适配到自己的机器人、摄像头和任务中。从 [Hugging Face](https://huggingface.co/runwayml/praxis-1-droid-nvfp4) 下载 NVFP4 检查点。
