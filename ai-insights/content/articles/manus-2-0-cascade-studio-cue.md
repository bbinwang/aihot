## Manus 2.0 正式登场
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/9ff88d637cf30f4a18572423e684f9572f79f15155469a7c20c51b397780c30d.webp)今天，我们非常激动地向大家介绍 Manus 2.0。

[视频/音频](https://d1oupeiobkpcny.cloudfront.net/assets/dashboard/materials/2026/09/28/9e16cfc6dbd4e33982113ccbb237cbdc67e723f6df1378a05701a95cf65ec5dc.mp4)
﻿Manus 2.0 不是一次简单的版本更新。它带来了全新的架构、全新的产品和全新的能力，而这一切都围绕着一个根本问题展开：下一代 Manus 应该是什么样子？

#### 1. 全新底座，走得更远
Cascade：我们自研 Agent 框架的最新迭代![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/4a2c0a0ffe750a7ea5687a114ef95f0c50bcb97880c07b7b898b3e1f2d2d5d95.webp)﻿它让项目从一开始就保持轻量，只在工作真正需要时才引入专业能力。简报、页面、视频和自动化流程，始终同属一个彼此关联的项目。效果更好，损耗更少。在一项测试配置中，与我们之前的系统相比，Cascade 的 Token 消耗减少 23.2%，任务完成时间缩短 28.2%，运行成本降低 32%。

##### 云电脑：给你的项目一个专属的家
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/8b77f84af55a1ec5d57729fe4d2a795e5d8fd154e01bff85ab8111edd5b3bb32.webp)﻿有些项目，一台机器已经装不下了。多人游戏需要一台在你合上笔记本后依然在线的服务器；自动化流程需要一个能全天候运转的地方。现在，你可以购买云电脑（Cloud Computer）：为有需要的项目提供专属运行环境，无论是游戏背后的服务器，还是自动化流程的长期驻地。

##### 自动化：从定时任务到事件触发的工作流
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/e1c5db7243a7d6b60b9d998bca4085a935d51f057e9a0a576b99f5fec1c2611f.webp)﻿以前，定时任务只能让 Manus 在设定好的时间开始工作。现在有了自动化（Automations），只要已连接的服务里发生了某件事，工作也能随之启动。一封新邮件、一次广告数据波动、一个日历事件、一条 Slack 消息、一次 Notion 更新，都可以触发任务。只需用一句提示告诉 Manus 要盯着什么、接下来做什么，它就会自动搭建并运行整套工作流。

#### 2. Manus Studio：从完成任务，到做出好作品
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/e9c1ad03b12c8099864c9b0e54a98fffefb8ef6eb0c1bffab6f9516fa17f8ef5.webp)﻿在 Manus 2.0 中，桌面应用升级为 Manus Studio：一个由人与 AI 共享的工作空间。每类工作都需要各自的专业工具，但如果把所有能力都塞进每一个任务，同样的工作只会变得更慢、更贵。所以 Studio 只引入项目真正需要的能力，让 Manus 的上下文始终聚焦在手头的工作上。
本次发布中，Studio 在日常办公和专业创作两方面都迎来了重大升级：文档、表格、PDF、幻灯片，以及网站、代码、游戏和视频。而在门槛格外高的视频和游戏领域，我们推出了两个全新的专业环境：视频编辑器（Video Editor）和游戏开发（Game Dev）。

##### 视频编辑器：几分钟出初剪，终剪由你把关
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/55cd7fee3e4c0778e4d7764896b6dbf1f321f4b3a49ee1ce6e6cf3c9aee7085f.webp)﻿假设你的新品广告明天就要上线，Manus 已经帮你剪好了初版。效果已经很接近了，只是你想换一首更温暖的歌，还想用自己拍的产品图，替换掉生成的那张。以前，这样的修改意味着重写提示词、把整个视频重新生成一遍。而在 Studio 里，Manus 直接把时间线交到你手上。它用到的片段、图片、文字、动态图形和音频，都以独立素材的形式摆在那里：你可以换掉配乐、放进自己的素材、挪一挪动画，满意了再导出。

[视频/音频](https://files.manuscdn.com/user_upload_by_module/session_file/310519663228112930/xSrrPlRGmNoAsLFC.mp4)
﻿你也可以把它交还给 Manus。让它再改一轮，它会在你修改的基础上接着做。视频编辑器专为短篇产品广告（30 到 60 秒）、AI UGC、数据动态图表、教程、Vlog 以及以动效为主的视频打造。完全不需要剪辑经验。

##### Alchemy 模式：让 AI 当你的创意总监
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/0ff6cad8ec122089840d836162d1eb78264b4ff1a6ce783eca5d3a015c9511bf.webp)﻿视频编辑器还提供 Alchemy 模式。你只需带着一个想法开始，Manus 就会接手创意指导，同时调用视频生成与代码生成能力。质量的提升大得出人意料：创意更新颖，画面细节把控更精准，动效更精致，剪辑节奏也明显更好。当质量是第一位时，就选 Alchemy 模式。之后你依然可以在时间线上精修成片。

##### 游戏开发：做出来，发出去，一起玩
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/6996dceb14f66d2a24b7ef10ccc4891a43411f85a0a45a07cbeb3bc18b6610de.webp)﻿大多数玩家心里都藏着一款想做了很多年的游戏。AI 已经能帮你做出一个还不错的版本，而 Game Dev 要帮你做出你心里真正想要的那一版。它同时调用视频、图像和编程模型。在 Max Ultra 模式下，你的游戏画面好看、玩法流畅、手感到位。从可玩的模板起步，第一次上手就能玩到自己的创意。在编辑面板中，你可以一边看着游戏运行，一边管理素材、修改代码，亲手调整角色移动、美术和场景。如果某个村民的头发应该是银色而不是棕色，选中那个村民改掉就行，其他一切原封不动。做好之后，可以把它发布成网站，任何人点开链接就能玩；也可以直接把朋友拉进来。多人联机，往往是这类项目最容易卡住的地方。它需要一台始终在线、所有玩家都能连上的服务器，这意味着托管、网络和运维，而这些大多数人从没打算去学。有了 Game Dev，你完全不必操心。设置只需点几下：配置 → 多人联机 → 选择云电脑 → 购买一台。 剩下的交给 Manus。竞速、对战、竞技和 3D 游戏统统支持。朋友们加入进来，他们在游戏里的发现，会塑造你的下一个版本。

##### 远程控制与 Computer Use：你的电脑，一句话就能调动
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/fa3607a5b7ea365d05955047195e2049a493b47383dad539305e06383bc9c4c1.webp)﻿远程桌面应用能让你在手机上访问电脑，但每一次点击，还是得你自己在小屏幕上完成。现在，你只需告诉 Manus 你要什么。比如你正坐在出租车上，急需家里电脑上的那份演示文稿。让 Manus 在发布会文件夹里找到最新版本发给你，同时你还能在手机上实时看着它操作桌面。想要 PDF 版？说一声就行。这一切都基于 Computer Use 实现。在已连接并授权的会话中，Manus 会在你电脑上一个独立、可见的工作区里操作，只使用你批准过的文件、浏览器和应用。它可以在你忙别的事时帮你测试应用，也可以在你离开时继续干活，而它做什么，始终由你掌控。

#### 3. Cue：Manus 推出的全新应用
![](https://files.manuscdn.com/assets/dashboard/materials/2026/09/28/972bc30a55a668ad2620114691959f5ee710a3d2c5792144050068a152b5b21b.webp)﻿Cue 是一款全新的独立应用，专为你的个人 Agent 打造，支持手机和桌面，与 Manus 基于同一套基础设施构建。给它一个 cue，它就立刻开工。每个 Agent 都有自己的身份在 Cue 中，每个 Agent 都拥有自己的邮箱、电话号码、钱包和电脑，因此它能发消息、在你设定的预算内付款，并在自己的机器上把任务从头到尾做完。它还能替你接电话，并在 Cue 里给你留一份通话摘要。组建团队把几个 Agent 拉进同一个群聊，给它们一个共同目标，它们就会互相接力：一个调研纽约发布会的场地，一个整理候选名单，第三个起草演示文稿。方向由你来定，最后也由你拍板。日常服务，交给 Agent 打理Cue 还能对接你身边的各种服务。在餐厅里扫一下二维码，你的 Agent 就能帮你点餐，或者帮你排队取号。
