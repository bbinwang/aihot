我们在 ChatGPT、Codex 和 API 中推出 Images 2.6,让你的创意更快变为现实。借助它，你可以用 GIF 为图像注入动态——从让品牌吉祥物或角色动起来，到把产品图变成吸睛的循环动画。你还能更快地打造精致视觉，并以更高精度进行打磨——在编辑过程中保持角色、产品和品牌细节的一致性。

如今，全球用户每周在 ChatGPT、Codex 和 API 中创作的图像达 40 亿张，平均每天创作超过 5 亿张。

更快的迭代与更专业的视觉效果

Images 2.6 的图像生成速度比之前快 50%。在 API 中，我们提供 GPT‑Image‑2.6 Flare 和 Sunburst 供开发者选择。当 quality 设为 low 时，Flare 最快可在六秒内生成图像。对于需要更高细节与精度的任务，GPT‑Image‑2.6 Sunburst 在 quality 设为 medium 或 high 时，可带来更高质量的图像生成，以及在多次编辑之间更强的图像一致性。Flare 还提升了海报、产品图像及其他专业视觉内容的排版质量。

用 GIF 让创意动起来

在需要动态呈现的时刻，GIF 能为你的创意增添另一个维度。营销人员和创作者可以为活动让品牌吉祥物动起来，为社交媒体制作表情反应和 meme,或在视频制作前借助动态分镜来探索角色的动作。

### 在 API 中解锁更多创建与编辑方式

借助 Images 2.6,开发者可以对图像的创建、编辑以及如何进入项目下一阶段拥有更多控制。此前已在 ChatGPT 中推出的图像标记(image markup)功能现已登陆 API,让团队能够精确定位需要进行特定修改的位置。SVG 导出功能则让设计可直接用于网站、应用和印刷。

新增的 complexity 参数让开发者可以调整模型为满足请求所做的规划程度，较低的设置适用于快速编辑。image quality 控制视觉细节与保真度，而 complexity 则决定场景构建的投入程度。

"GPT‑Image‑2.6 将速度与创意控制融为一体，帮助你在生成和编辑图像的同时，保留那些定义角色、产品或品牌的细节。我们很高兴将其加入 Figma Weave,为团队提供又一个用于创意生产的强大模型，并且全部在可复用的工作流内完成。"
—Itay Schiff,Figma Weave 创意总监

对于大多数编辑任务，我们建议使用低 complexity 以获得更快的编辑速度，并搭配你的工作流所需的 image quality。对于元素较多或约束较多的场景，可尝试中或高 complexity effort。
