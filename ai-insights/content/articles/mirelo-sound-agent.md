## 认识 Sound Agent:一句话为你的视频做声音设计

**Mirelo Sound Agent 是 Mirelo Editor 中的一款 AI 声音设计 Agent,可以通过自然语言提示编辑视频的音频。上传一段无声或混音糟糕的视频，说出你想要的声音，Agent 就会分析画面和声音，生成音效和音乐，将对话与背景分离，移除音乐，配音翻译成其他语言，并在时间轴上为你移动剪辑片段。它在每个付费步骤前都会显示费用，而且只处理音频，所以画面会保持你剪好的样子，分毫不变。**

[试用 Sound Agent](https://mirelo.ai/audio-editor)

如今的视频模型在生成画面的同时也会生成声音，对于单个片段来说这可能已经够用了。但把几个片段拼接成一条视频后，问题就显现出来：你从未要求过的音乐、每个镜头中听起来都不一样的汽车声、每个剪辑点都在跳变的氛围声，而且除非重新生成你喜欢的那一版，否则什么都没法改。Sound Agent 把这份控制权还给你，每次一个提示。

### 你可以让 Sound Agent 做什么？

| 领域 | Agent 的作用 |
| --- | --- |
| **理解视频** | 在进行任何更改之前，先分析画面和声音 |
| **音效** | 根据视频本身或文字描述生成音效 |

| **时间轴编辑** | 放置、移动、复制、拆分、删除和恢复剪辑片段，调整速度，添加轨道和提示标记，让你在多个版本之间选择，并撤销更改 |
| **费用与确认** | 在每个付费步骤前显示费用，达到你设定的额度上限时停止，并在删除任何内容前先询问 |

### 创作者可以用 Sound Agent 做什么？

#### 一步到位为整段视频配上声音

> “为这段视频做声音设计”

上传一段无声或混音糟糕的视频，Agent 会判断画面里是什么，然后围绕它构建音效和氛围声。接下来你只需继续提问，直到它听起来和你想象中的一样——不需要时间轴技巧，也不用翻找素材库。

#### 移除音乐，或换成合适的那一首

> “移除音乐，给我来一段紧张的弦乐”

那些在生成片段时自带、情绪不对或无法使用的音乐会被移除，而且 Agent 在生成新曲目之前会先建议一个方向。你可以要求不同的情绪，它会描述有哪些变化，让每一版都更贴近你的要求。

#### 清理并重新平衡混音

> “把人声从背景中分离出来”

播客、Vlog 和外景录音中，人声常常被其他声音淹没。Agent 会将对话与背景分离，这样你就可以调低一个、调高另一个，或只保留语音。

#### 把一个声音精确放到你想要的位置

> “在 0:12 处加一声关门砰响” · “把呼啸声放慢”

当剪辑已接近完成、只差某一个瞬间时，说出声音和时间点，或你想修改的片段。Agent 会把它放到时间轴上，你还可以通过下一条提示来移动、复制、拆分或撤销。

#### 为整个场景铺上氛围

> “在整个场景下加上雨中城市的氛围声”

叙事短片和氛围片段的成败取决于画面动作之下垫着什么。说出你想要的氛围声或房间底噪，Agent 会把它铺在场景下方，让同一地点的每个镜头听起来都像同一个地方。

#### 将视频带到另一种语言

> “把这段翻译成西班牙语”

对于进军新市场的品牌和角色配音工作，Agent 可在同一个项目中将视频配音成 32 种语言中的任意一种。

#### 保留对白、去掉某个声音或改变音色

> “添加音效，保留他们说的话” · “去掉电话铃声” · “让旁白的嗓音更低沉”

- **保留对白** - 为口播视频、UGC 视频或广告视频生成音效，同时保留真实的语音
- **移除指定的单个声音** - 去掉某个单独的声音，比如狗叫或电话铃声，其余内容全部保留，且原始音频一键即可恢复
- **改变音色** - 调整角色的口音、语气或音高，同时保持台词和时序不变

### Sound Agent 是如何工作的？

1. **将视频上传到 Mirelo Editor** - 可以是无声的剪辑片段、生成的序列，也可以是想要修改声音的录音
2. **说明你的需求** - 用自然语言描述声音效果，可以宽泛到“给这段做声音设计”，也可以精确到“在 0:12 处加一声关门声”
3. **查看方案和费用** - Agent 会分析视频，告诉你它将做什么，并在任何付费步骤执行前显示费用
4. **试听并继续调整** - 用下一个 prompt 继续优化，在多个版本之间选择，或撤销某项修改，直到满意为止
5. **导出** - 完成后，将最终配乐连同你的视频一起带走

### 如何掌控费用？

每个付费步骤在运行前都会显示费用，因此不会在你不知情的情况下产生任何扣费。Agent 还会在达到 credit 上限时停止（初始为 1,000 credits，可以自行修改），并在删除任何内容前征求你的批准；所有修改都可撤销，也可以随时回到之前的版本。

### 常见问题

#### Sound Agent 会剪辑视频本身吗？

不会。Sound Agent 只处理音频。它会修改时间线上的音效、音乐、对白和音频片段，而画面保持你剪辑好的原样。

#### 我需要剪辑或声音设计经验吗？

不需要。你只需用自然语言描述想要的效果，Agent 会完成时间线上的操作——从在指定时间点放置声音，到拆分或移动片段。你只需写下想要的改动，Agent 就会执行。

#### 它能去掉视频里的音乐并保留对白吗？

可以。Agent 会将对白从背景中分离出来并移除音乐，还能按照你指定的方向生成一条新的音乐。

#### 它支持配音成哪些语言？

Sound Agent 支持配音成 32 种语言。只需在 prompt 中说明语言，例如“把这段翻译成西班牙语”。

#### 费用是多少？

Sound Agent 使用你 Mirelo 账户中的 credits。它会在每个付费步骤前显示费用，并在你可自行调整的 credit 上限处停止，因此你始终清楚每次请求的花费。免费和付费方案请参阅[定价](https://mirelo.ai/pricing)。

#### 我可以撤销 Agent 做的修改吗？

可以。你可以撤销修改、恢复被删除的片段，并在声音的不同版本之间选择；Agent 在删除任何内容前也会征求你的批准。

#### 我在哪里可以使用 Sound Agent?

Sound Agent 位于 Mirelo Editor 中。
