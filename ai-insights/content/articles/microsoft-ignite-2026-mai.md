在 MAI，我们的使命是为您打造全球最顶尖的模型，并使每一位开发者和企业始终处于能力的前沿。

但随着 token 支出的激增，我们深知您还需要具备价格优势的模型，以便您能够全天候运行 Agent 来执行实际的工程工作。

这就是为什么今天我们要发布一系列七款全新世界级模型，提供真正卓越的性能价格比：

**阵容如下：**

- **[MAI Cyber 2 Flash](https://microsoft.ai/news/introducing-mai-cyber-2-flash/)** 在 CyberGym-E2E 基准测试中，以低于 GPT-6 Astra 质量的表现，实现了不到其 2% 的单任务成本。
- **[MAI Code 2](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)** 以约 40% 的价格达到了 GPT-6.1 Sol 98% 的代码质量。与 Opus 5.5 相比，它以仅 5% 的价格达到了 96% 的性能。
- **[MAI Code 2 Flash](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)** 以 65% 的价格匹配 GPT-6 Luna 的性能，以 20% 的价格匹配 Haiku 5.5 的性能。
- **[MAI Image 2.7](https://microsoft.ai/news/introducing-mai-image-2-7/)** 在 Artificial Analysis 图像编辑榜单上排名第一，以仅五分之一的价格超越了 GPT Image 2.6 Sunburst (max)。
- **[MAI Realtime 1](https://microsoft.ai/news/introducing-mai-realtime-1/)** 性能优于 GPT-Realtime 2.1，且起步价仅为每分钟音频 0.01 美元。
- **Dragon Copilot Transcribe** 基于 MAI Transcribe 2 构建，这是全球最快、最准确的多语言转录模型，目前已每月支持 1000 万次患者问诊，并将多语言错误率减半。

### 专为 24-7 运行而构建的前沿网络安全防御

安全、对齐和隔离是 2027 年及以后 Agent 开发最重要的优先级。这是我们的首要任务。我们需要运行监控和控制 Agent，全天候防御和修补在线生产系统。这就是 **[MAI Cyber 2 Flash](https://microsoft.ai/news/introducing-mai-cyber-2-flash/)** 被设计为以极低的成本提供前沿智能的原因。

基于微软数十年的专有数据和世界级的安全专业知识构建，我们的模型帮助防御者在这个攻击者拥有廉价且丰富的进攻工具的新时期保持安全。

MAI Cyber 2 Flash 建立在防御者已经依赖的早期 MAI Cyber 模型之上。MAI Cyber 占据了 MDASH 中近 40% 的扫描量，并且 90% 以 MAI 开始的扫描继续使用它。我们最新的模型在输出 token 上的价格比 MAI Cyber 1.1 Flash 低 86%，为现有的 MDASH 客户提供更强且更便宜的模型。

### 以极低的成本实现惊人的编码性能

**[MAI Code 2](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)** 专为日常企业级编码任务提供最佳性价比。在针对我们在 GitHub Copilot 中看到的日常企业级编码任务的四个广泛使用的基准测试（DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas 和 FrontierCode v1.1）中，MAI Code 2 以 40% 的价格提供了 GPT-6.1 Sol 98% 的性能，以仅 5% 的价格提供了 Claude Opus 5.5 96% 的性能。

我们构建这些模型是为了优先处理客户每天进行的编码工作。它们尚未针对更困难的问题进行调优，例如基础科学研究和长周期的 Agent 工作。

MAI Code 2 还经过调优，能够生成出色的仪表板和可视化效果。在一项盲测的并排前端工作评估中，开发者在 64% 的情况下更偏好 MAI Code 2 而非 GPT-6 Sol。今天即可在 [GitHub Copilot](https://github.com/features/copilot) 中试用 MAI Code 2。[在此阅读更多](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)。

[MAI Code 2 Flash](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/) 专为高容量的日常任务而设计，如代码解释、针对性编辑、常规修复和快速迭代，同时以更低成本提供高质量结果。在衡量日常、高容量常规编码任务的三个编码基准测试（DeepSWE 1.1、Terminal Bench 2.1 和 SWE-Atlas）中，它的表现与 GPT-6 Luna 和 Claude Haiku 5.5 相当，价格分别为后两者的 65% 和 20%。它已在 [GitHub Copilot](https://github.com/features/copilot) 中可用，并在 [Microsoft Foundry](https://azure.microsoft.com/en-us/products/ai-foundry) 中以有限访问预览形式提供。

### 全球最佳的图像和转录模型

[MAI Image 2.7](https://microsoft.ai/news/introducing-mai-image-2-7/) 是全球最佳的图像编辑模型，在 Artificial Analysis 上排名第一，以仅五分之一的价格超越了 GPT Image 2.6 Sunburst (max)。在文生图生成方面，我们的模型排名第四，使我们成为第二好的实验室。**MAI Image 2.7 Flash** 为高容量场景提供世界级的图像生成能力，每张图像成本约为 10 美元。两者均可在 Microsoft Foundry [此处](https://azure.microsoft.com/en-us/products/ai-foundry) 获取。

**[MAI Realtime 1](https://microsoft.ai/news/introducing-mai-realtime-1/)** 是我们的首款实时语音到语音模型，专为自然、低延迟的对话而设计。在我们的评估中，它在外部基准和 Dynamics 365 基准测试中均优于 GPT-Realtime 2.1。其定价适用于企业级规模使用，起步价低至每分钟音频 0.01 美元，可节省预算。您可以在 [MAI Labs](https://labs.microsoft.ai/?model=mai-realtime-1) 中试用，并[在此注册您的兴趣](https://forms.cloud.microsoft/r/AQcVUgqpZZ)。

**Dragon Copilot Transcribe** 基于 MAI Transcribe 2 构建，现已在 Dragon Copilot 中上线，支持 100% 的医患对话转录。它每月处理 1000 万次诊疗，将多语言工作流中的错误率降低了一半，并已在美国三分之一的医生手中使用。

### 市场上领先的决策模型

**[Decision 1.1](http://aka.ms/decision-model-ga)** 将模型路由功能直接集成到您的应用程序中，确保只有在真正需要时才使用更大、更昂贵的模型。在 AA Decision Index 中，微软领先于 Jev、Google 和 OpenAI，同时速度更快、成本更低。已有 4,000 家客户在使用，其速度比 GPT-6.1 Sol 快 50 倍，成本仅为后者的 1/79。

### 为您的业务定制模型

我们反复听到领导者的反馈：没有人愿意将自己的智慧倾注到别人的模型中。

如果你基于开源权重进行开发，你真的能信任它们的来源吗？或者，当你将其作为你最宝贵的知识产权和数据的基础时，你真的能信任它们的行为表现吗？

我们听到了你们的声音。我们推出了自定义模型。AT&T 为 5G 网络运营分析开发了一个 MAI 自定义模型，其性能超越了 GPT-6.1 Sol，且成本仅为后者的 1/50。在复杂场景中，他们发现 Code 2 以显著低于替代方案的价格提供了前沿级别的性能。

今天，我们通过 **[MAI 授权权重](https://microsoft.ai/news/introducing-mai-licensed-weights/)** 迈出了重要的一步：由你掌控的模型。

选取一个前沿 MAI 模型，如果需要，可以使用你的专有数据对其进行定制。然后在你自己的 Azure 环境中安全地运行它。

你控制谁能访问它。你的数据和适配始终归你所有。我们将通过 Frontier Company 与你合作，交付自定义模型，并将其嵌入到你自己的产品和 Agent 中。

这就是 MAI，一个拥有卓越性价比的世界级模型家族：全球最佳图像编辑模型；全球最佳转录模型；以 2% 的成本实现前沿网络安全防御；以及你可以规模化扩展的世界级日常编码模型。

关键在于，这一切都伴随着 **Your IQ**、**Your agents**、**Your weights**。一切都在你的掌控之中。

这是你可以信赖的前沿智能，来自你可以信赖的公司。
