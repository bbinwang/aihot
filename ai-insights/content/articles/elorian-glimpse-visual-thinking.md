一瞥，是观看的起点。当模型知道什么值得再看一眼，理解便由此开始。

Glimpse 是一种全新类别的视觉思考模型：一个能够基于所见对物理世界进行推理的系统。Glimpse 可以追踪运动中的物体、适应不断变化的视角，理解各部件如何组合在一起，并将观察与接下来会发生的事情关联起来。这种理解能力在机器人、科学发现和创意产业中至关重要。

与现有的前沿大型语言模型相比，Glimpse 在将视觉表征融入推理过程本身方面走得最远。它可以在视觉空间中进行推理，随着思考的展开不断回顾并细化内部视觉表征，同时也更 grounded,学会了围绕物体及其空间关系进行推理。作为一个 Agent,Glimpse 还经过端到端训练，能够使用编写代码、转换图像和观看视频的多模态工具；Glimpse 还能生成并协调多个 subagent,在它们之间交换文本、视觉产物和内部表征，共同解决一个问题。这些能力结合在一起，使 Glimpse 能够审视问题，并在推理过程中不断修正自己的解读。

在多模态基准测试中，Glimpse 达到了与 GPT-6 Astra 和 Claude Opus 5.5 相当(有时甚至超越)的前沿水平，同时模型规模显著更小、成本显著更低。我们以一个小团队、仅用几百块 GPU 开发了 Glimpse,在一个开放权重的 base model 上完成了 post-training。Glimpse 现已通过 API 和我们的 chat UI 提供。

### 模型结果

在涵盖科学图表推理、开放词汇计数、短视频 captioning 和操作事件理解的四项评测中，Glimpse 超过了 Astra,并在具身推理上与之持平。这些能力可支撑一系列应用：从分析实验室数据、为社交媒体视频打标签，到识别机器人录像中已完成的动作。

总体而言，Glimpse 在一整套多模态基准测试中都具有竞争力。输入 token 价格为每百万 0.60 美元，输出 token 为每百万 3.00 美元：两种费率分别比 GPT-6 Astra 低 94%,比 Claude Opus 5.5 低 85%,比 GPT-6.1 Sol 低 70%,比 Gemini 3.8 Flash 的首发定价低 20%。
