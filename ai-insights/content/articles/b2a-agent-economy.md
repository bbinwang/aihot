互联网的主要用户已不再是人类，而是 AI Agent。

Agent 如今已占据网络流量的多数，撰写了网上新发布文章的一半以上，并生成了推送到生产环境的绝大部分代码。

[https://d1lamhf6l6yk6d.cloudfront.net/uploads/2026/11/Bot-vs.-Human-Web-Traffic-Share-Combined-scaled.png](https://d1lamhf6l6yk6d.cloudfront.net/uploads/2026/11/Bot-vs.-Human-Web-Traffic-Share-Combined-scaled.png)

这就是平台变革早期阶段的样子：采用率可以测量，但它所催生的商业模式大多尚未显现。以往每一次变革都同时改变了人们能做什么，以及企业如何触达他们。Web 给了企业一个任何人都能访问的店面；移动端把这个店面装进了每个人的口袋。AI 已经改变了人们能做的事情，但它对分发的变革才刚刚开始。

随着 Agent 从回答问题转向完成任务，它们将越来越多地代表我们决定使用哪些产品、订阅哪些服务，以及把钱花在哪里。

将 Agent 视为一等客户的企业有机会迎来一波增长。不这样做的企业则可能发现自己正面临威胁。多年来，零售商和平台筑起高墙将 bot 挡在门外——现在，它们将不得不去争夺 bot 的生意。

如果 Agent 能够突破到真正的消费者群体并捕获真实的使用量，它们将解锁 AI 领域最大的尚未实现的机会：一场真正的平台变革。以往每一次平台变革(web、移动)都是将新的产品能力与新的分发机制相结合。AI 在前者上表现超预期，在后者上却不及预期，这是 ChatGPT 之外消费者采用度一直如此有限的重要原因。

[https://d1lamhf6l6yk6d.cloudfront.net/uploads/2026/11/Platform-Shifts.png](https://d1lamhf6l6yk6d.cloudfront.net/uploads/2026/11/Platform-Shifts.png)

分发变革的早期迹象已经出现。ChatGPT、Claude 和 Grok 等 LLM 对许多企业而言是规模庞大且极具价值的流量来源。Shopify 报告称，2026 年第一季度其店铺的 AI 驱动流量同比增长了八倍，而来自 AI 搜索的订单增长了近十三倍。而且这一趋势还在加速：Human Security 观察到，agentic 浏览器流量在 8 月至 10 月间增长了 8 倍，其中 Muse 带来的活动占比最大(60%),OpenAI 产品合计占 30%。

[https://d1lamhf6l6yk6d.cloudfront.net/uploads/2026/11/AI-Agent-Traffic-Grew-8%C3%97-in-Two-Months-Combined-scaled.png](https://d1lamhf6l6yk6d.cloudfront.net/uploads/2026/11/AI-Agent-Traffic-Grew-8%C3%97-in-Two-Months-Combined-scaled.png)

正如网站能够比广告牌更有效地触达用户，Agent 理论上应该是一种更强的流量来源——因为它们掌握着关于用户及其需求的深度而具体的数据。到目前为止，这一点已被证实——AI 引荐的消费流量比非 AI 流量具有更高的参与度、更好的收入转化，且跳出率更低。即使在 Agent 出现之前，据估计美国已有 11% 的购物旅程在访问交易网站之前先访问了 AI。

[https://d1lamhf6l6yk6d.cloudfront.net/uploads/2026/11/AI-Referred-Consumer-Traffic-Is-High-Value-Traffic-Combined-scaled.png](https://d1lamhf6l6yk6d.cloudfront.net/uploads/2026/11/AI-Referred-Consumer-Traffic-Is-High-Value-Traffic-Combined-scaled.png)

目前，这些流量大多是通过浏览器操作产生的——Agent 要么接管用户的浏览器，要么启动自己的虚拟机和浏览器实例，然后像人类一样通过点击来完成任务。然而，我们开始看到类似 Agent 版 App Store 的东西正在兴起，但功能更为强大——connectors、插件和 MCP，使 Agent 能够更直接地访问第三方工具和网站。

举个例子——我们让 ChatGPT 使用 Krea、Descript 和 Eleven Labs 插件来创建并编辑一个视频广告。它在这些产品之间进行协调，还为了完成视频说服我们升级到 Descript 的付费方案。

            [https://a16z.com/welcome-to-the-b2a-economy/#](https://a16z.com/welcome-to-the-b2a-economy/#)
                    
    

随着底层平台允许用户将其身份或 token “借给”其他产品以完成任务（例如 [Sign in with ChatGPT](https://help.openai.com/en/articles/20001410-sign-in-with-chatgpt)），使用 Agent 注册或支付产品只会变得越来越容易。最终，Agent 将能够在无需人工干预的情况下选择并安装所需的工具——Claude[已允许](https://x.com/ClaudeDevs/status/2117680635561312732)企业管理员为其整个组织接入插件。就在昨天，OpenAI[推出了](https://openai.com/index/introducing-businesses-chatgpt/) Businesses in ChatGPT——企业现在可以认领自己的企业、添加产品 feed，并查看用户在 ChatGPT 上如何与其互动的洞察。

有几类公司可能从 B2A 经济中受益：

- **Agent / agentic 模型**——大多数人把“消费级 Agent”想象成 Instinct、Muse 和 Wabi 这类独立的 harness。我们相信，随着其背后的模型变得更加以行动为导向，每个产品很快都将以 agentic 方式运行。ChatGPT（拥有 12 亿周活跃用户）在这方面有着尤为引人注目的机会。
- **因 Agent 而得以实现的新产品**——Amazon 需要互联网才得以诞生，而没有手机就不会有 Uber。我们预计 Agent 也会催生属于自己的例子。具体形式难以预测，但一些主题包括自动运转的 SMB、由 AI 居间撮合的市场或网络产品，以及自动优化器。
- **为 Agent 进行优化的现有企业**——LLM 已经成为许多网站的重要流量来源，这也[构成了生成式引擎优化](https://a16z.com/geo-over-seo/)（GEO）行业的基础。GEO 基本止步于发现环节。Agent 将更进一步，深入到购买/注册选择的评估与执行环节，这是一个更大的市场。
- **Agent 基础设施**——Agent 要代表其人类用户在现实世界中运作，需要自己的一套工具。在相当低的 Agent 流量规模下，我们已经在支付、欺诈与身份、通信（iMessage、电话、电子邮件等）方面看到了系统压力。

我们已经有一个关于这一切可能如何演变的案例研究——coding agent，它们彻底改变了开发者的行为。截至 2026 年 9 月，超过 40% 的 GitHub PR 始于 Agent 的草稿——而六个月前这一比例仅为 17%。

与消费级 Agent 一样，coding agent 也必须依赖外部工具来完成任务。假设用户让一个 Agent 搭建一个网站，完成这项工作可能需要数据库、托管、身份验证、邮件发送和监控。除了 agentic 模型和 harness 本身(Cursor、Codex、Claude Code、Cognition,以及 Replit、Lovable、Base44 等 vibe coding 平台)之外，许多其他玩家也实现了增长：

- Supabase [报告](https://supabase.com/blog/supabase-series-f)称，2026 年 6 月，超过 60% 的新数据库由 AI 工具创建
- Neon [报告](https://www.databricks.com/company/newsroom/press-releases/databricks-agrees-acquire-neon-help-developers-deliver-ai-systems)称，2025 年 5 月，其 80% 的新数据库由自动化 Agent 部署
- Stripe [报告](https://stripe.com/blog/stripe-projects-adds-new-agents-providers-developer-controls)称，2026 年 6 月，Agent 占其文档流量的近 40%,以及 API 资源 CLI 请求的 70%
- Vercel [报告](https://vercel.com/blog/vercel-ship-2026-recap)称，2026 年 10 月，由 Agent 触发的部署在过去 12 个月中增长了 28 倍

全球劳动力中开发者的占比不足 1% —— 当另外 99% 的人开始使用 Agent 时，会发生什么？

这是我们探索 Agent 经济系列文章的第一篇。将其称为"AI commerce"其实低估了这一机遇 —— 没错，Agent 会为实体产品和服务带来交易量，但它们还将重塑流量、token 和收入流向数字产品的方式。出于对欺诈和拒付(chargeback)的担忧，大多数企业目前仍在拦截 Agent 流量，但我们认为，他们将不得不拥抱这股价值与日俱增的浪潮。

在接下来的几周里，我们将发布更多洞察与数据，内容包括：消费者 Agent 的使用现状、Agent 如何决定将流量导向哪些网站和产品、围绕 Agent 的基础设施如何发展，以及 Agent 要完成交易还需扫清哪些障碍。

这个领域每天都在变化 —— 以下是我们目前对这一市场的最佳梳理，其中包括 Agent 本身，以及让它们得以存在的基础设施。
