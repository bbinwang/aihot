Argon 擅长在编码、金融、法律、网络安全和科学等领域的复杂真实世界任务中进行深度工作。Argon 在多步骤任务中展现的深度与精确性，使其在[跨领域 benchmark](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/#workingharder)上超越其他前沿模型，并在衡量金融、编码、法律和税务等关键经济领域模型性能的 [Vals Index](https://www.vals.ai/benchmarks/vals_index) 上排名第一。

### 解决复杂工程任务

在 Google,我们一直在将 Argon 用于最棘手的工程问题。过去几周里，软件工程师们交付高质量代码的速度比以往任何时候都快。Antigravity 中的 Argon 帮助团队将 agentic 代码提交量提升了 35% 以上，同时将代码回滚减少了近三分之一。

- **理清 Chrome 中的浏览器功能代码：** Argon 帮助 Chrome 团队将核心网页处理逻辑从 Chromium 4000 万行代码库中一个约 600 万行的浏览器功能遗留目录中分离出来。[通过一次输送多个干净的代码变更](https://issues.chromium.org/issues/540709814),Argon 帮助团队完成了跨越数百个文件的架构重构，将数月的工作在数周内完成。对于 Chrome 全球数十亿用户而言，这将解锁让正在运行的网页在标签页、侧边栏和浮动窗口之间流畅切换而无需重新加载的能力，从而消除一整类浏览器崩溃。

  

  

  
    
  
    

  

  

  
    

  
    

- **在数小时内优化生产级 Python 代码库：** Antigravity 中的 Argon 正在帮助 Google 开源 [Agent Development Kit](https://github.com/google/adk-python)(ADK)背后的团队进一步推进其性能工程——ADK 是一个为企业 Agent 提供支持的框架。团队向 Argon 提供了他们的 [.agents/skills](https://github.com/google/adk-python/tree/main/.agents/skills) 规则手册和一段话的目标：在不破坏现有应用的前提下消除框架开销。Argon 自主通宵工作，找出了多项优化(现已[上线于 google/adk-python](https://github.com/google/adk-python/commit/1754b3eeb6cdb2c16e3b30619a12066623df132e)),将长会话中的内存内会话准备时间缩短了 40%,并将冷导入速度提升了 21%。阅读[工程深度解析](https://developers.googleblog.com/optimizing-a-200000-line-python-codebase-overnight-with-gemini-4-argon)了解更多。
- **量子化学开源软件包优化：** xTB(Semiempirical Extended Tight-Binding)是分子领域被引用最多的开源量子化学软件包之一。科学家用它来预测分子的 3D 形状，并筛选大量药物和材料候选。借助 Antigravity 中的 Argon,我们的研究人员让 xTB 预测分子结构的速度提升了最高 2.3 倍，构象搜索(conformer search)速度提升了 1.8 倍。这些更改已贡献至 GitHub 上的官方 [xTB 仓库](https://github.com/grimme-lab/xtb/pulls?q=is%3Apr+author%3Ag8j39+%28created%3A%3E2026-10-05+created%3A%3C2026-10-10%29)。
- **让我们的开源 Gemma 模型速度提升近三倍：** 借助 Argon,我们仅用几天时间就在 A100 上通过 vLLM 实现了 2.85 倍的端到端推理加速(在 Gemma 4 E2B 上将吞吐量从约 37,900 token/秒提升至超过 108,000 token/秒)，同时保持 100% token 一致性且零质量下降，而这一过程通常需要数月。查看[上游 pull requests](https://github.com/vllm-project/vllm/pulls?q=is%3Apr+author%3Alucianommartins+%28created%3A%3E2026-10-05+created%3A%3C2026-10-10%29)(涵盖从 attention 调优到 speculative decoding 的各项优化)以了解具体更改。
- **交付复杂的 3D 可视化：** 与之前的 Gemini 模型相比，Argon 在空间推理、数学精度和视觉编码方面带来了重大改进。通过使用 /goal 等 slash 命令，以及在 Antigravity 中通过提示词驱动带有自定义 skills 的多 Agent 循环，Google 员工正在使用 Argon 以可直接在浏览器中渲染的原生代码构建复杂 3D 可视化、高保真游戏和交互动画的原型。

Argon 在 Antigravity 中利用多智能体视觉反馈循环，构建了一个高度精细的宝塔模型。该模型在 Blender 中自主雕刻出一个多建筑寺庙综合体，具备照片级真实的建筑、植被和光照效果。

Argon 在 Antigravity 中通过多智能体循环，将真实书桌的照片转化为一个可玩的微型赛车游戏。书桌物体、房间和赛道使用 Blender MCP 进行建模和碰撞检测，使用 Nano Banana 进行纹理处理，并在 Three.js 中集成来自 Gemini Omni Flash 的物理效果、自定义着色器以及汽车引擎音效。[立即尝试](https://aistudio.google.com/apps/bundled/desk-racer?showAssistant=true&showPreview=true&fullscreenApplet=true)（在 Google AI Studio 中）。

Argon 在 Antigravity 中编写 Python 脚本，利用多智能体视觉反馈循环过程化地雕刻、绑定、动画制作和 PBR 烘焙一个复杂的 3D 游戏，随后在 Three.js 中将其接入 Web，集成 GLSL 着色器、破碎物理效果和单人 AI。[立即尝试](https://aistudio.google.com/apps/bundled/wizard-chess-3d?showAssistant=true&showPreview=true&fullscreenApplet=true)（在 Google AI Studio 中）。

Argon 使用零外部库和 100% 纯 Python，编写了自己的 3D 光线追踪引擎，并配备自定义视频工具和音频混音器，从头构建并记录了一个阳光充足的图书馆场景。该视频由 Gemini 3.8 TTS 语音旁白和 Lyria 3.5 音乐制作而成。查看 [源代码](https://github.com/google-gemini/gemini-4-demo-vanilla-3D)。

在 Antigravity 中，Argon 从一张 Nano Banana 图像开始，驱动 Blender MCP 进行自主循环，对齐相机网格、雕刻哥特式建筑并编排音频响应式光照，从而创建出一个完整的 3D 场景。

### 变革关键业务与专业工作流

Argon 融合了前沿推理能力、深度视觉感知、扩展的领域知识以及更强的写作能力，涵盖法律、金融、科学和编程等领域，助力高风险的专业工作流。它沟通清晰，让你始终掌握进展，并比之前的任何 Gemini 模型更好地遵循风格指令。Argon 回答问题更直接，减少模棱两可的表述，避免不必要的重复，并在整个回复中摒弃陈词滥调。

参与早期访问计划的企业客户和初创公司已经在使用 Argon 时取得了显著成果。

凭借先进的推理和多模态能力，同时保持严格的 grounding（事实依据），Argon 在深度多模态文档理解、纵向数据分析以及交互式分析沙箱方面表现卓越。

看看 Argon 如何合成约 50 GB 的机载 LiDAR 扫描数据、GIS 房间矢量、Library of Congress CAD 图纸以及 NPS 档案，重构 Chaco Canyon 的 3D 模型，将碎片化的考古记录转化为可探索的数字遗产站点。[立即试用](https://aistudio.google.com/apps/bundled/chaco-canyon-3d?showPreview=true&showAssistant=true&fullscreenApplet=true)，尽在 Google AI Studio。

在 Gemini App 中，Argon 通过自定义 skill 将一个充满项目上下文的非结构化文件夹整理成一份整洁的客户提案演示文稿。随后 Gemini 起草该演示文稿并通过电子邮件发送给客户，同时通过定时任务为今后所有传入的客户请求创建自动化工作流。

观看 Argon 将来自 3 个开源仓库的数据合成为一个医学学习工具，你可以在 3D 探索人体的过程中逐层剥离解剖结构、查看临床元数据并触发生物力学模拟。

在 Gemini macOS 应用中，Argon 借助 Antigravity 使用 Nano Banana 为一款沙发的新沙发腿生成多个设计迭代方案，然后为其中一个生成可 3D 打印的文件。从一张标注尺寸的草图和一张沙发照片出发，Argon 构建的模型尺寸精准，完美适配沙发。

在 Isomorphic Labs,团队将 Argon 作为合作伙伴来加速药物发现与设计的研究工作流。Argon 能够快速综合复杂的 PDF 和专利以提取关键信息，将通常需要数周才能完成的过程缩短至数小时。

### 与研究人员和领域专家携手加速现实世界的影响力

研究人员、工程师和安全专家已经在使用 Argon 推动网络防御、科学、数学和机器人技术的边界。它正在帮助网络防御者和研究人员检验假设、自主审计关键代码库和形式化证明，并捕捉隐蔽的 zero-day 漏洞和逻辑缺陷。

#### 将最先进的网络安全能力带给更多可信的防御者

从今天开始，我们将扩展至数百个新的 [Fairwind Program](https://deepmind.google/fairwind-program/) 合作伙伴。

[Wiz](https://www.wiz.io/) 已经在其 "[Scan for Good](https://www.wiz.io/blog/scan-for-good-critical-ai-exposures)" 计划中使用 Argon,该计划免费为公共利益保护关键基础设施。凭借对模型的早期访问权限，Wiz 已经展示了 Argon 在多个高风险领域的现实影响力：

- **保护敏感的政府数据：** 作为一项长期开展的网络安全韧性计划的一部分，并与一家联邦机构合作，Argon 帮助主动识别并修复了一个可能导致敏感数据和政府基础设施暴露的缺口。这项工作帮助防止了关键安全部门开发细节的泄露，以及对专用模型的未授权访问。
- **保护关键医疗基础设施：** Wiz 还使用 Argon 保护重要的医疗基础设施。通过串联多个复杂漏洞，该模型帮助团队发现并快速修复了一个公开文件下载绕过漏洞，该漏洞暴露了主密钥并授予了管理员访问权限。Argon 不仅仅是发现漏洞，还主动保护了数十万份私人患者记录。

#### 开启新的科学突破

Argon 已经在科学界产生了真实世界的影响——帮助多个领域的科学家和专家实现全新发现。

- **量子计算:** Argon 正在帮助我们的研究人员加速量子纠错和算法设计方面的进展。为了让错误解码器能够实时跟上量子硬件的速度，Argon 将我们的 ML 量子纠错解码器 [AlphaQubit](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/alphaqubit-quantum-error-correction/) 的内部版本转换成了单个高度优化的硬件 kernel——将推理吞吐量提升近一倍，使我们能够部署更大、能力更强的模型并扩展到更大的量子设备，同时继续满足严格的实时阈值要求。Argon 还在降低量子子程序的时空成本。对于 arcsin——近期量子模拟算法中的一个基础组件——由 Argon 编写并经 Lean 形式化验证的实现，相比已发表的量子 CORDIC 基线将时空成本降低了 100 倍以上，这是迈向优化量子电路标准库的一步。
- **核聚变:** 仿星器是极其复杂的机器，是实现无限清洁聚变能的主要候选方案之一，但优化其 3D 磁场以难度大而著称。自 1967 年以来，一个被称为 “Grad 猜想” 的长期假设认为，为这些磁场找到精确的数学解是不可能的，直到近期出现了反例，其中包括马里兰大学的 Matt Landreman 教授发现的反例。如今，Google 的一个团队与 Landreman 教授合作，发现了[更广泛的一类 Grad 猜想反例](https://arxiv.org/abs/2610.07304)。这些新解为聚变界提供了可靠的基准，用于测试他们的仿星器模拟代码，而这些代码是未来设计中的宝贵工具。
- **罕见病研究:** Gamow Labs 的研究人员使用 Argon 分析了患有罕见发育性肺疾病的新生儿的去标识化基因组。在一个案例中，Argon 精确定位了一处常规软件多年来未能发现的染色体重排，并解释了它为何未被检测到。在基于真实临床和实验室数据构建的 Gamow Labs 私有 evals 上，Argon 在 [RareBench](https://gamowlabs.com/benchmarks)(罕见病诊断辅助方面为 57%)和 [LabBench](https://gamowlabs.com/benchmarks)(湿实验推理方面为 52.2%)上均名列第一。这些进展意味着面临罕见疾病的家庭能够更快获得诊断。详情请参阅[博客](https://gamowlabs.com/bringing-expert-genome-interpretation-to-every-nicu)
  [2](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/#footnote-2)

- **酶设计:** 工程化具有精确反应性的酶以耗时长而闻名，通常需要数月的定制化模型调优和候选筛选。丝氨酸酯酶是一类能够切割目标分子上酯键的酶，广泛用于回收利用以及药品、生物燃料和洗涤剂的制造。我们的科学家与 Argon 合作设计丝氨酸酯酶，以基准分子 4MU-acetate 为目标——该分子在酯键断裂后会在紫外光下发光。在短短几个小时内，Argon 完成了相关数据的汇集、模型调优，并确定了多个受生物化学启发的过滤器，最终得到了五个全新设计。随后的实验室测试证实，这些设计均具有强大的催化活性。成功生成酶的速度和便捷性展示了酶工程在生物制造、绿色化学和药物开发等领域实现快速加速的潜力。
