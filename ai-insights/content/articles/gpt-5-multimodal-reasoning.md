# GPT-5 正式发布

OpenAI 于本周发布 **GPT-5**,这是自 o 系列推理模型之后的又一次大版本升级。

## 核心能力

- **实时视频理解**:支持对视频流的低延迟理解,延迟降至 300ms 以内
- **工具并行调用**:一次对话中可同时调度多个工具,复杂任务成功率提升 27%
- **推理成本**:相比上一代下降约 40%,长上下文缓存命中率显著提高

## API 示例

```python
from openai import OpenAI

client = OpenAI()
resp = client.chat.completions.create(
    model="gpt-5",
    messages=[{"role": "user", "content": "分析这段视频里的技术要点"}],
)
print(resp.choices[0].message.content)
```
