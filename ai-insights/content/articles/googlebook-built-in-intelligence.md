##### 探索其他风格：

出色的硬件需要能够真正跟得上的软件，因此我们在设计 [Googlebook](https://googlebook.google/?utm_source=blog.google&utm_medium=owned&utm_campaign=launch_blogpost) 时配备了一套智能系统，将 Gemini 直接带到您的设备上。它能预判您的需求，简化您的日常任务，并主动帮助您完成工作。以下是一些让 Googlebook 独具助益的功能。

### 使用 Magic Pointer 更智能地工作。

Magic Pointer 重新发明了几十年来的指向和点击计算机体验。

只需快速晃动光标，Magic Pointer——它能理解文本、图像和上下文——就会将 Gemini 带到您正在工作的地方，让以前繁琐的任务变得轻而易举。以下只是使用 Magic Pointer 的几个示例。

- **即时日程安排：**在网页上突出显示一份复杂的马拉松训练计划，然后让 Gemini 自动规划这些跑步日程并将其安排到 Google Calendar 中。
- **保障您的安全：**将鼠标悬停在可疑电子邮件上，让 Gemini 分析其中的文本和图像，以验证它是垃圾邮件还是合法信息。
- **组合视觉效果：**使用 Magic Pointer 选择一组图像，并让 Gemini 将它们一起可视化。无需下载、上传或编写提示词。只需指向、提问、得到结果。

从第一天起，我们在构建 Magic Pointer 时就将隐私置于核心。它只会在被晃动召唤时才会启动，在你不用时保持关闭。

### 通过 Rambler 与你的 Googlebook 自然对话。

  

  

  
    

  
    

    
  

  

  
    

  
    

    
  

  

标准的语音听写会把你说出口的一切都原样记下——包括结巴、错误和填充词。而清理这些内容，可能比用键盘打出你的想法还要费时。Rambler 则能真正理解你话语背后的上下文和细微含义。

比如，当你更想收工结束一天时，却还得起草团队会议记录。只需打开 Rambler,让你的意识流尽情流淌。Rambler 会把杂乱无章的口头内容加以整理：修正错误，将行动事项归纳为结构化的项目符号列表，甚至会添加相关的 emoji。它还原生支持多语言，你可以在句子中途切换语言，而思路毫不中断。

### 用 Create My Widget 打造专属于你的 Googlebook。

Googlebook 上的 Create My Widget 让你无需任何编程经验即可构建自己的 widget。只需描述你想要什么，就能打造定制 widget。你可以创建一个来追踪你最爱的体育球队的比分，或者为下一次家庭旅行创建一个可视化倒计时。

如果你想更进一步，每台 Googlebook 都随附 Google Antigravity。你可以用它编写自己的应用，然后直接部署到你的 Googlebook 上。开发者还可以使用完整的 Linux 终端环境，运行 Claude Code 或 Antigravity CLI 等工具，直接在 Googlebook 上进行严肃的 agentic coding。

### 借助 Gemini 和 Chrome,即刻上手。

你在 Chrome 和 Android 上熟悉并使用的强大 Gemini 功能在 Googlebook 上开箱即用，包括任务自动化、Gemini Live,以及根据屏幕内容为你提示下一步操作的主动建议。你甚至可以合上笔记本电脑，让 Gemini Spark 在后台处理复杂请求并完成任务。
