### 对话发生在声音中

想象一位女士在暴风雨期间打电话报告树木倒在她的财产上。她站在雨中，手机信号很差，她的儿子一直在问一些问题，而在读到一半地址时，她停下来回答儿子。

任何在这通电话另一端的人都会自然而然地理解发生了什么。他们会听到她转过身去，等她转回来，忽略雨声，并接着她中断的地方继续读取地址。

目前大多数正在使用的语音系统无法可靠地做到这一点。它们是级联系统：将语音转换为文本，将文本传递给语言模型，再将回复转换回语音。每一步都会丢弃通话的一部分信息：谁在说话，他们在跟谁说话，他们是否犹豫，以及他们是否已完成。

Tofu-1 的工作方式不同。它直接监听音频，因此声音携带的信息对模型保持可用。它同时倾听和说话，因此呼叫者可以像对待真人一样打断或纠正它。而且它可以在说话的同时继续处理请求，因此在查询某些信息时通话不会停滞。

对于银行、医疗系统或政府机构来说，听错的通话意味着未提交的欺诈索赔、未续开的处方或未批准的福利。以下各节将逐一介绍这些能力，并附有录音和图表。

### 聆听整个场景

Tofu-1 理解音频，而不仅仅是文字。它能区分不同的说话人，识别短语的意图对象，并将语音与通话中的其他声音分离：哭泣的孩子、电视、高速公路上的汽车、医院对讲机和按键音。它还能听出说话的方式，包括犹豫、沮丧和紧迫感。

回到那位站在雨中的女士。当她转身回答儿子时，她的声音仍然能传达到麦克风。转录文本会准确记录她的话语，但会忽略最重要的事件：她的注意力离开了客服人员。将每个短语都视为请求一部分的系统可能会回答本意是说给孩子的话。将重叠的人声视为噪音的系统则会丢失通话中正在发生的事情。

### 电视测试

房间里的一台电视是最难处理的案例之一。广告说“立即拨打”。新闻主播问了一个问题。一个角色说“是的”。每个短语都是清晰、可理解的语音，且都不是针对电话中的 Agent 说的。

我们称之为**电视测试**：模型能否在忽略属于其他场景的语音的同时，跟随呼叫者的思路？降噪无法解决这个问题，因为电视不是噪音。它是来自错误来源的语音，而且通常比呼叫者的声音更大。

1. Agent 问道

“确认一下，您想取消您的保单吗？”
2. 呼叫者

没有说话。她仍在寻找她的保单号码。
3. 房间里的电视

“是的！”
基于转录的 Agent

可能会将“是的”视为她的回答并取消保单。
Tofu-1

旨在将“是的”归因于电视，并要求呼叫者确认。

这是一个说明性的电视测试场景，并非录制的模型输出。电视的“是的”与呼叫者的声音一样清晰；唯一的区别是来源不同。

要通过测试，模型必须在新的声音不断到达时跟踪它正在帮助的人，并认识到其他语音可能完全属于另一场对话。音量不能决定一切。嘈杂的电视可能无关紧要，而呼叫者轻声的纠正可能是通话中最重要的内容。

这是有极限的。如果背景噪音使得呼叫者无法被理解，Tofu-1 应该说明这一点，并要求他们重复或移动到更安静的地方。忽略电视绝不能成为猜测呼叫者说了什么的理由。

### 边说边听

在电话通话中，人们经常互相打断。他们会说“嗯嗯”来表示他们在跟进，插话以修正成员 ID 中的数字，并在问题结束前就开始回答。Tofu-1 是**全双工**的：它同时听和说，它听到的内容可以改变它正在说的内容。

难点在于判断。当 Agent 复述保单号码时，简短的“对”意味着继续。“不，是 4，不是 9”意味着停止。模型必须在句子中途区分这两者，并且必须防止电视抢占话语权，同时让呼叫者轻声的纠正通过。

### 边说边想

高风险通话涉及实际工作：验证呼叫者身份、检查索赔状态、查询福利和确认付款。电话中的人在这些工作进行时仍会与呼叫者交谈。Tofu-1 也是如此。对话和推理并行运行，因此模型在工作继续时保持响应。

概念性插图。对话可以在工作完成之前改变工作，并且答案反映呼叫者说的最新内容。

同时运行两者有一个陷阱：在工作进行中时，呼叫者可能会更改请求。如果病人在查询过程中纠正了预约日期，答案必须反映新日期。“我正在检查”和“您的付款已通过”是不同的承诺。Tofu-1 不会声称某事已完成，直到它确实完成。
